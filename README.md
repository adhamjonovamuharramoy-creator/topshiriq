## Men haqimda

- **Yo‘nalish:** Internet va axborot kommunikatsiyalari
- **Qiziqishlarim:** Dasturlash, sun’iy intellekt, Data Science.
- **O‘rganayotgan sohalarim:** Backend Development, Python, Big Data.
- **Maqsadim:** Malakali IT mutaxassisi bo‘lish va foydali loyihalar yaratish.
